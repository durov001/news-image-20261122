Entry for the [make.fun](https://make.fun?ref=zsk0hsg3) bounty
[news-image-20261122](https://make.fun/bounty/news-image-20261122): sum up
Sunday 22 November 2026's world news in one image.

A cream newspaper front page — **37 stories across 9 regions**: COP31 collapses
in Antalya, Ukrainian drones strike a Russian warship off Libya, BepiColombo
reaches Mercury, plus a UTC timeline, the day in numbers, a region bar, a
world map with pins, and a DATE CHECK box naming stories dropped because they
belong to another day. Every story is dated 22 November 2026 (UTC) and carries
a source badge (CONFIRMED / OFFICIAL / REPORTED). All art is original flat
vector work drawn with PIL.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
# writes out/entry.png (1024x1024, deterministic)
```

## Files

- `main.py` — entrypoint: copies `entry.png` to `$MAKEFUN_OUTPUT_DIR`
- `entry.png` — the front page (1024×1024)
- `LICENSE` — MIT
